# 📘 전산회계1급·전산세무2급 학습 퀴즈 (ERP 기출 퀴즈에서 출발)

기출문제 HWP 파일(이론문항)에서 문제·보기·정답·해설을 자동으로 뽑아내고,
터미널이나 휴대폰 브라우저로 바로 풀어볼 수 있는 개인 학습용 퀴즈 도구입니다.

- 대상: 회계/생산/인사/물류 × 1급/2급, 2022년 1월 ~ 2026년 5월 (총 23회차)
- 문제 수: 3,995문제 (이론만 -- 실무는 다루지 않음, 아래 참고)
- 이론문제 중 75문제는 첨부 이미지가 있어서 문제 화면에 같이 표시됩니다.
- 2023년 3~5회는 원본이 PDF로만 존재해서 이번엔 제외 (추후 별도 작업 필요)

**실무(더존/영림원) 문제는 다루지 않습니다.** 실제로는 ERP 프로그램을 직접
조작해서 값을 조회해야 풀리는 시뮬레이션 문제라, 프로그램 없이 문제·보기만
봐서는 학습 의미가 없다고 판단해서 뺐습니다.

---

## 폴더 구조

```
erp_quiz/
├── extract.py        ← HWP 시험지를 questions.json 으로 변환 (pyhwp 사용)
├── quiz.py           ← 실제로 문제를 풀어보는 CLI 퀴즈
├── web_app.py        ← 휴대폰 브라우저로 풀 수 있는 웹앱 버전 (Flask)
├── templates/        ← web_app.py 가 쓰는 화면
├── static/images/    ← 이론문제 첨부 이미지 (extract.py 가 자동으로 채움)
├── quiz_exe_빌드.bat  ← 파이썬 없는 컴퓨터에서도 돌아가는 .exe 빌드 스크립트
├── questions.json    ← 추출된 문제 은행 (커밋됨, extract.py 재실행 없이 바로 사용 가능)
├── wrong_log.json    ← 오답노트 (자동 생성/갱신, 커밋 안 됨)
└── erp_source/       ← 원본 HWP/DOCX 시험 자료 (커밋 안 됨, 저작권 있는 원본이라 제외)
```

## 사용법

### 1. 문제 풀기 (questions.json 이 이미 있으므로 바로 실행 가능)
```bash
python quiz.py                              # 전체 문제 중 무작위 20문제
python quiz.py --count 10                   # 문제 수 지정
python quiz.py --subject 회계 --level 1급    # 과목/급수 필터
python quiz.py --round "2026년 5월 기출문제" # 특정 회차만
python quiz.py --review                     # 예전에 틀렸던 문제만 재출제
python quiz.py --round "2026년 5월 기출문제" --subject 회계 --level 1급 --count 999
                                              # 특정 회차의 특정 과목/급수 시험지 통째로 풀기
python quiz.py --list                       # 사용 가능한 과목/급수/회차 목록 보기
```
문제를 보고 1~4 중 답을 입력하면 정답 여부와 해설(있는 경우)을 바로 보여주고,
틀린 문제는 `wrong_log.json`에 자동으로 쌓여서 다음에 `--review`로 다시 풀 수 있습니다.

### 2. 문제 은행 다시 만들기 (원본 HWP 파일을 바꿨을 때만 필요)
```bash
pip install pyhwp beautifulsoup4
python extract.py                # erp_source/ 전체를 다시 읽어서 questions.json 갱신
python extract.py --limit 3      # 파일 3개만 처리 (테스트용, 빠름)
```

### 3. 파이썬 없는 컴퓨터에서도 실행할 .exe 만들기
```bash
quiz_exe_빌드.bat
```
`dist\ERP기출문제퀴즈.exe` 와 `dist\questions.json` 두 파일이 생성됩니다.
**이 둘은 항상 같은 폴더에 있어야 합니다** (exe 가 옆에서 questions.json 을 찾습니다).
이 두 파일만 복사해서 옮기면 파이썬이 설치되지 않은 다른 Windows 컴퓨터에서도
더블클릭으로 바로 실행됩니다. (오답노트 `wrong_log.json` 도 exe 옆에 자동 생성됩니다.)

### 4. 휴대폰 브라우저로 풀기 (웹앱)
```bash
pip install flask
python web_app.py
```
실행하면 콘솔에 두 개의 주소가 뜹니다:
- `http://127.0.0.1:5000` -- 이 컴퓨터에서 확인용
- `http://192.168.x.x:5000` -- **같은 와이파이에 연결된 휴대폰**에서 이 주소를 브라우저에 입력

휴대폰에서 접속한 뒤 브라우저 메뉴에서 **"홈 화면에 추가"**를 하면 아이콘이 생겨서
앱처럼 쓸 수 있습니다.

웹앱에는 두 가지 모드가 있습니다:
- **일반 연습**: 과목/급수/회차를 고르고 무작위로 문제 수만큼 뽑아서, 문제마다
  바로 정답/해설을 보여주며 풀어보는 모드.
- **시험모드** (`/exam`): 과목/급수와 범위(회차 하나 또는 연도 전체)를 골라서
  그 이론 문제 전체를 실제 시험처럼 풀어보는 모드. 문제마다 정답을 바로 안
  보여주고, 끝까지 다 풀고 제출하면 한번에 채점 + 문제별 정답/해설을 보여줍니다.

## 웹앱: 복습·통계·시험 타이머 (store.py)

- **복습 간격**: 맞히면 1일 → 3일 → 7일 → 14일 → 30일 뒤에 다시 나오고, 틀리면 바로 오늘 복습 대상이 됩니다.
  "오늘 복습할 문제만" 체크로 이론, 실무 카드 모두 이 대상만 풀 수 있습니다.
- **서버 저장**: 학습 기록은 SQLite(`data/study.db`)에 이름 단위로 저장됩니다. 같은 이름이면 다른 기기에서도 이어집니다
  (비밀번호는 없어서 개인용 전제). 예전 쿠키 오답노트는 처음 접속할 때 한 번 자동으로 옮겨집니다.
  **클라우드 배포 시** 재배포해도 지워지지 않는 디스크를 만들고 환경변수 `DATA_DIR` 를 그 경로로 지정해야 합니다.
- **약점 현황** (`/stats`): 실무는 유형별, 이론은 회차별 정답률과 오늘 복습할 개수.
- **시험모드 타이머**: 제한 시간(분)을 정하면 카운트다운하고, 끝나면 안 푼 문제는 오답으로 채점합니다. 결과에 합격 기준 70% 표시.
- 화면에는 전산회계1급·전산세무2급만 노출됩니다 (`web_app.py` 의 `EXAM_LABELS`).

## 실기 환경: 전표 입력 연습 · 시험 시뮬레이션

- **전표 입력 연습** (`/lab`): 실무 카드처럼 답을 펼쳐 보는 대신, KcLep처럼 차/대변 · 계정(이름 또는 코드) · 금액을
  직접 입력하면 `grader.py` 가 정답 분개와 비교해 채점합니다. 매입매출 문항은 유형 · 공급가액 · 부가세도 입력합니다.
  일반전표 · 매입매출 · 오류수정('수정 후' 분개 입력) · 결산정리 문항이 대상입니다.
  채점 기준은 줄 단위 부분점수(없는 줄을 더 쓰면 감점)이며, 실제 시험의 부분점수 규칙이 아니라 연습용입니다.
- **실기 시험 시뮬레이션** (`/sim`): 회차 하나를 이론(객관식) 30점 + 실무 70점으로 제한 시간(회계1급 60분 · 세무2급 90분 기본)
  안에 풉니다. 문항 번호로 오가며 풀 수 있고, 제출하거나 시간이 끝나면 합계 점수와 합격(70점) 여부, 유형별 득점을 보여줍니다.
  기초정보 · 장부조회 · 부가세신고 · 원천징수처럼 답이 KcLep 화면인 문항은 자동 채점이 안 되어, 결과 화면에서 정답 화면을 보고
  직접 체크해 점수에 반영합니다.
- 두 모드 모두 결과가 복습 간격 기록(위 섹션)에 들어가 `/stats` 의 유형별 정답률에 반영됩니다.
- 테스트: `python -m unittest test_grader` (확정답안 분개를 그대로 입력하면 전 문항 만점이 나오는지 확인).

## 문제 데이터의 한계

- 이론문제 중 일부(초반 사례형/개념형 문제 894개)는 원본 학습자료 자체에 정답이
  표기되어 있지 않아 채점 대상에서 제외됩니다.
- 실무(더존/영림원) 문제는 다루지 않습니다 (위 설명 참고).
